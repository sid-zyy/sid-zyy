### 🛠️ Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**Aequitas**](https://github.com/sid-zyy/Aequitas) | Offline video understanding for public safety on one 6 GB laptop GPU. 4-bit quantization and speculative decoding take a window from 4.11 s to 1.16 s with no detections lost | Python · FastAPI · React/TS · Ollama · Qdrant |
| [**Argus**](https://github.com/sid-zyy/Argus) | A 7-agent incident responder: agents investigate real logs and git history, a fact-checker tries to disprove each cause, and fixes ship only after a human approves | Python · FastAPI · Docker · LLMs |
| [**attention_head-modularity**](https://github.com/sid-zyy/attention_head-modularity) | Code for my ICONICA paper: pairwise ablation of 10,706 head pairs across 4 models to test whether attention heads act independently | Python · PyTorch · TransformerLens |
| [**fedddi**](https://github.com/sid-zyy/fedddi) | HARBOR: robust federated drug-drug interaction prediction, benchmarked against 16 aggregation defenses under poisoning attacks | PyTorch · GNNs · Flower · Hydra |
| [**shortify**](https://github.com/sid-zyy/shortify) | URL shortener with a Base62 hashing pipeline, live on AWS Lambda + DynamoDB (race-safe conditional writes) | Node.js · Express · MySQL · React · AWS SAM |
| [**memallocator**](https://github.com/sid-zyy/memallocator) | `malloc`/`free` replacement using `sbrk` for small blocks and `mmap` for large ones, with splitting and coalescing | C · POSIX |
| [**basic-shell**](https://github.com/sid-zyy/basic-shell) | A small Unix shell built from scratch on `fork`/`execvp` | C · POSIX |
